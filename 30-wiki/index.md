# Wiki Index — 根路由器 (MOC)

> **这不是目录，而是路由器。** 问题来了先**最先**读这里，只决定去哪个**主题**。个别实体行不放在这里——那是主题路由器（`{topic}/index.md`）和类型索引（`{topic}/indexes/{type}.md`）的工作。

## 🧭 路由 (2 段)

```
问题 → [根路由器] 哪个主题? → [{topic}/index.md] 哪个类型/分片? → 页面
```

- **Phase A (Route, 不读页面)：** 从问题中提取实体·类型意图·运算 → 用 `{topic}/aliases.md` 规范化 → 只看路由器决定**要展开分片的最小集合**。
- **Phase B (Search, 只读分片)：** 仅展开选定的分片筛选候选 → 正文 + `[[链接]]` 一跳 → 仅以依据引用作答。未命中时 → 兄弟分片 → grep → lazy 生成/无结果。

详细规约：`00-system/conventions.md` §0·§7·§9。
