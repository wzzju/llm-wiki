# 10-inbox — 未处理源入口（收件箱）

> **新源放入这里。** 这个文件夹是尚未整合进维基的源的**队列（流）**。`/compile` 处理后，原始文件会被移到 `20-raw/`（永久保管）。所以**留在 inbox 里的 = 还没编译的**。

## 添加数据的方法

1. 把源文件放进这个文件夹（直接放入，或用 `/ingest <URL|文件>` 自动收集）。
   - 格式：`.md` / `.txt` / `.pdf`（文章·论文·笔记·转录稿等）
   - 推荐文件名：`YYYY-MM-DD-标题-slug.md`
   - 如果是网页文章，把正文复制保存为 `.md`，并把出处 URL 写在文件最上方。
   - 源引用的图片·figure 直接放到 `20-raw/assets/`（永久资产 → 链接稳定）。
2. 在 Claude Code 中运行 `/compile`（维基化）。
   - `/compile`（不带参数）→ 查找 inbox 中未编译的源并依次维基化
   - `/compile 10-inbox/2026-06-19-article.md` → 仅处理特定源
3. 处理完成后：
   - 合成结果会作为页面累积到 `30-wiki/`（更新路由器·类型索引·aliases），
   - **原始文件会自动移到 `20-raw/`** 永久保管（不可变）。

## 规则

- inbox 是**流（队列）**，`20-raw/` 是**仓储（永久原始文件保管）**——两者角色不同。
- inbox 里还有文件，就是"有待办（未处理源）"的信号。
- 含个人信息·密钥的文档，放入前请脱敏（参见 `.gitignore` 的 PII 块）。
- inbox 本身不作为 LLM 的修改对象。只是读取 → 维基合成 → 移到 raw。
