# 20-raw — 处理完成的原始文件（不可变保管库）

> 这个文件夹是 **source of truth**。经 `/compile` 维基化完成的原始源会从 `10-inbox/` 移到这里永久保管。LLM 只读，**绝不修改·删除。**

## 如何填充

- 新源放进 `10-inbox/`（入口）。**不直接放进这里。**
- `/compile` 把 inbox 源合成进维基（`30-wiki/`）后，**将原始文件移到此文件夹**。
- 所以在 `20-raw/` 里的 = 已反映进维基（已编译）的源。

## 角色

- 维基页面的所有事实主张都反向引用到这里的原始文件（`[[sources/...]]` → frontmatter `source_file: 20-raw/...`）。
- `assets/` 永久保管维基页面引用的图片·figure·PDF（URL 可能失效，建议下载）。

## 规则

- LLM 把 raw 当作**只读**处理。合成·摘要·交叉引用都发生在 `30-wiki/`。
- 想修改原始文件时不要修改，而是把新版本作为新文件加到 `10-inbox/` 重新 `/compile`（保留历史）。
- 含个人信息·密钥的文档，放入 `10-inbox/` 前请脱敏（参见 `.gitignore` 的 PII 块）。

## 图片·PDF

- LLM 无法一次读取 markdown 内联图片，所以先读文本，再单独查看需要的图片（`00-system/conventions.md` §10）。
