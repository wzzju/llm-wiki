# 20-raw — 처리 완료 원본 (불변 보관소)

> 이 폴더는 **source of truth**입니다. `/compile`로 위키화가 끝난 원본 소스가 `10-inbox/`에서 여기로 옮겨와 영구 보관됩니다. LLM은 읽기만 하고 **절대 수정·삭제하지 않습니다.**

## 어떻게 채워지나

- 새 소스는 `10-inbox/`에 넣습니다 (진입점). **직접 여기에 넣지 않습니다.**
- `/compile`이 inbox 소스를 위키(`30-wiki/`)에 합성한 뒤, **원본을 이 폴더로 이동**합니다.
- 그래서 `20-raw/`에 있는 = 이미 위키에 반영(컴파일)된 소스입니다.

## 역할

- 위키 페이지의 모든 사실 주장은 여기 원본으로 역참조됩니다 (`[[sources/...]]` → frontmatter `source_file: 20-raw/...`).
- `assets/`에는 위키 페이지가 참조하는 이미지·figure·PDF를 영구 보관합니다 (URL은 깨질 수 있으므로 다운로드 권장).

## 규칙

- LLM은 raw를 **읽기 전용**으로 다룹니다. 합성·요약·교차참조는 모두 `30-wiki/`에서 일어납니다.
- 원본을 고치고 싶으면 고치지 말고, 새 버전을 새 파일로 `10-inbox/`에 추가해 다시 `/compile` 하세요 (이력 보존).
- 개인정보·비밀키가 든 문서는 `10-inbox/`에 넣기 전에 마스킹하세요 (`.gitignore`의 PII 블록 참조).

## 이미지·PDF

- LLM은 마크다운 인라인 이미지를 한 번에 읽지 못하므로, 텍스트를 먼저 읽고 필요한 이미지를 별도로 봅니다 (`00-system/conventions.md` §10).
